# Bioconnect 音の設計 — Meadow Steps

2026-09-28。BGMと効果音を更新。ルール版16は変更しない。

## 狙いと音の出どころ

草原・動物のゆるさと、長く遊んでも操作を邪魔しにくい響き。
参考として挙がったスイカゲームから取り入れるのは軽やかさ・親しみやすさという方向性のみ。
既存曲の音源、メロディー、楽譜、サンプルは流用せず、新たな旋律と伴奏を作った。
波形とノイズもWeb Audioで生成し、外部音源・音声サービス・追加の通信は使わない。

## BGM

- 曲名: **Meadow Steps**。96 BPM / 4拍子 / ニ長調 / 16小節 / 40秒。
- 木琴風の主旋律、柔らかい三角波の和音、丸い低音、種を振るような小さなリズム。
- 前半と後半で旋律を変え、休符・音量差・微小なタイミング差を入れる。
- 単純な同音量の正弦波の反復から、複数パートを重ねた曲へ変更。
- 音楽の時計はAudioContext基準で先読み予約。速度切替だけでは曲頭に戻さない。

## 効果音

- 草/芽の配置: 約0.22秒の「ざっ」。葉の擦れを模した3層の帯域制限ノイズ。
- 合体/連鎖: 約0.23秒の「ぽんっ」。短い下降ピッチで丸い輪郭を作る。
- 配置音の約0.1秒後から145ms間隔で、段数ぶん音程を上げて鳴らす（最大11段）。
- 合体が起きる配置でも「ざっ」を鳴らす。象到達時は最後に小さな木琴のフレーズ。
- 食事音は短く控えめ。連鎖中の食事音は抑える。
- Ready/Goも同じ木の音に統一。新しい配置では古い連鎖の予約を取り消し、連打の重なりを抑える。

連鎖の盤面表示は従来どおり最終結果を一度描く。音の段数は一致するが、段階的な画面演出を新設したわけではない。

## 停止・再開

2026-10-02変更: ON/OFFボタンは廃止し、BGMと効果音は最初からオン。消したいときは端末のマナーモード（iPhoneの消音スイッチ）で切る。
SafariではAudio Session を `ambient` にして消音スイッチに従わせる。Web Audio のみを使い、`<audio>` 要素は使わない（消音を無視して鳴るため）。
ブラウザの自動再生制限により、音は最初のタップ／キー入力で始まる。
BGMはタイトル・ガイド・ゲーム中・終了画面でも流れ続け、非表示タブでのみ止まる。効果音は従来どおりゲーム一時停止中は鳴らさない。
BGMの音量バスを0.7→1.6に上げた（コンプレッサーで頭打ち）。新しいゲームでは曲位置と予約をリセットする。

## ファイル

- `audio-synth.js`: 楽譜、楽器、効果音、音声ノードの解放。
- `audio.js`: 操作との接続、スケジューラ、個別ON/OFF、一時停止。
- `concepts/audio-v1/index.html`: 4種類の試聴ページ。
- 同フォルダの `meadow-steps.wav`: 完成ループ40秒。`grass-plant.wav`: 配置音。
- `animal-chain.wav`: 配置＋5連鎖。`gameplay-mix.wav`: BGMと操作音を重ねた12秒。
- WAVはゲーム本体と同じ楽器・音量でOfflineAudioContextから書き出した確認用。ゲームの起動時には読み込まない。
- `render-preview.cjs`: 試聴音源を書き出す道具。ローカルサーバーとNodeのPlaywrightが必要。`BIOCONNECT_PREVIEW_URL`でURLを変更可（既定8770）。

## 確認結果

- 構文検査成功。既存ルールテスト **206 passed / 0 failed**。
- Chromeで実際のボタン操作: Sound/Musicの独立On/Off、Ready/Go、配置、3連鎖、ガイド開閉、新規ゲーム、ゲーム終了→再挑戦。
- 非表示/復帰はvisibilityイベントを模擬し、音声コンテキストとタイトルの停止維持を検証。
- 11段連鎖中のOffで残りの音が鳴らないことを確認。音声出力をAnalyserNodeで測定。
- OfflineAudioContextの5ケースすべてに有効な非無音波形。BGMピーク0.185、混合0.256、ストレス入力0.273（上限1）。クリッピングなし。
- 40秒ループ接続部のサンプル差は約0.000000038。試聴ページは375px幅でも横はみ出しなし。
- 外部Supabaseライブラリの取得失敗に伴う既存エラーは発生。ゲームと音は動作。クラウド同期は今回未検証。
- 未確認: 本人の耳による好み・端末ごとの聴感音量、スマートフォン実機、Safari実機、実タブのバックグラウンド復帰。

音の心地よさは波形検査だけでは判定しない。次は本人の試聴に応じ、木琴の丸さ・テンポ・BGMと効果音の比率を調整する。
