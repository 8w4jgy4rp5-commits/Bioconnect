# Bioconnect 版16 バランス確認（2026-09-27）

## 変更と意図

発見段階が高いほど上位手札が増える仕組みを廃止。固定の芽/草から全動物を合体で育てる。
後半の難度と報酬を時間の経過に合わせて上げ、突然の植物枯死は減らした。

停止中は進まない。Relaxedは秒数が倍。植物寿命は同じ期間で徐々に短くなる。
表の倍率は既存の表示スコア曲線に写す前の生点へ適用する。待つだけのスコアはない。

## 配分の比較

固定植物の草40%/50%を各careful/banking60試合で比較。40%のオオカミ到達33%/12%に対し、
50%は45%/47%、表示点中央値は6704/6483対6607/6781。草50%を選んだ。
サンプルはランダムであるため精密な率の差を保証しない。高位配給を復活せず育成の手間を減らすための選択。
