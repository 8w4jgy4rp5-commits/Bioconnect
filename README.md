## 目指しているゲーム
Web版を先に育てる。ひとつの盤面で食物連鎖と爽快な合体・連鎖を楽しみ、象への到達とハイスコアを目指す。
操作と世界の時計は独立。配置した手札はすぐ補充。Startを押すまで時計は止まる。
進行順は 芽→草→ウサギ→キツネ→シカ→シマウマ→バッファロー→オオカミ→クマ→ライオン→トラ→ゾウ。
手札は芽50%・草50%で固定。動物はすべて合体で育てる。時間や発見で上位の手札は出ない。ルール版は16。
世界の25tickごとに春→夏→秋→Winter 1〜5と進み、石と枯れの圧力・合体/捕食の生点倍率（×1〜×8）が上がる。
現在のバランス検証と未確認点は `docs/balance-v16-verification.md`。
象は合体で生まれた動物を食べる特別なルールで、空腹速度250%、捕食点400%。
スコア表示は10000に近づく曲線と6段階の称号。過去の点数・版番号は履歴と区別する。

## 開発方針
- 会話は日本語、ゲーム内の表示は英語。
- 食物連鎖・爽快感に沿うローカル調整、実装、検証は都度確認なしで進めてよい。
- 公開、費用発生、広告・購入の有効化は別途確認。コミット・pushは明示依頼まで行わない。
- 到達可能というだけで「面白い」と断定しない。実測と仮説を分け、本人の試遊を判断に反映する。
- 作業が終わるたびに PROGRESS を更新し、決定した方針は DEVELOPMENT に反映する。

移行時点の画像実装: ウサギ・キツネ・オオカミ・クマ（親子）。クマの最新作業も含めて取り込み済み。

## 次に取り組むこと
1. 残りの動物イラストを確認し、採用したものをゲームへ組み込む。
2. スマホでも連鎖の経路・最終着地点が分かる表示と段階的な演出。
3. ゆっくり操作した場合の難易度と、食事・合体の両方を狙う意味。
4. 象への到達・再挑戦・ベスト保存・スマホ画面の確認。
細かな優先順位はその時のユーザーの依頼を優先する。広告・購入は設計段階。

## ファイル案内
- `index.html` / `style.css` / `script.js` / `audio.js`: ゲーム本体。
- `img/`: ゲーム用画像。原画があれば `img/ref/` も保存対象。
- `concepts/animal-art-v1/`: 動物の原画・候補・比較画像・書き出し道具。
- `concepts/start-screen-v1/`: タイトル画面の比較案。
- `concepts/imported-from-chatgpt/`: 別の作業フォルダにあったシカ・シマウマ・クマの画像と生成時のメモ。
- `ASSETS.md`: 全画像の所在と、採用状況を読むための注意。
- `shared/`: 元のプラットフォームから引き継いだ保存同期・フッター・言語設定。外のフォルダには依存しない。
- `PROGRESS.md`: このゲームだけの最新進捗と過去の関連履歴。
- `DEVELOPMENT.md`: 方針・未完了項目・仕様を決めた理由。
- `docs/history/`: 移行前の記録とルールの原文。過去資料なので現在の指示として扱わない。
- `docs/migration-manifest.json`: 移行元、コピー先、コピー時のファイル照合値。
- `docs/verification.md`: 独立化後の動作確認結果。

## ローカルで開く・確認する
このフォルダで `python -m http.server 8770 --bind 127.0.0.1` を実行し、`http://127.0.0.1:8770/` を開く。
ルールテストは `node rules.test.js`、試遊シミュレーションは `node sim.js 30`。
ゲームのバランスを変えた場合は複数の操作速度で調べ、画面の変更はブラウザでも確認する。

## 保存・公開・バックアップ
保存データ互換のため `ecosystem-puzzle` という内部キーは維持。フォルダ名と別の役割なので一括置換しない。
クラウド同期のコードと公開用Supabase設定はそのまま引き継いだ。新しいURLではブラウザ保存とログイン状態は自動では移らない。
今回移したのはファイルであり、ブラウザ内のベスト記録やログイン状態ではない。
同期はログインと通信がある場合のみ。通信不可時は既存のブラウザ保存への切替を使う。
本番は移行していない。HTMLのcanonical・共有用URL・解析設定は既存公開版のものを維持。将来の公開先が決まったら見直す。
独立したGit管理を初期化済み。まだコミット・リモート登録・pushはしていない。旧Git履歴は元リポジトリに残る。
この場所はOneDrive外。PC間の共有・外部バックアップは別途必要。
