# プレイ画面の「変な方向」4案（2026-10-04）

外部フィードバック「4+や子ども向けを狙わないなら、全部変な方向に振るのが効く。ポップよりラヴクラフト風とか。そうすれば TikTok / YouTube / Instagram がずっとやりやすい」を受けた候補。どれも未採用。
ui-v2 と同じ試合途中の場面（夏・4,210点・空腹のオオカミ・手札は草→ウサギ→芽）の静止モック。

- `a-eldritch.html` — ラヴクラフト風。黒緑の古書、銅版画風の動物、空きマスで目がまばたき、盤面の裏から触手。餌は「Offerings」。
- `b-googly.html` — 切り貼りコラージュ。雑誌の切り抜き風の動物、場所を無視したギョロ目、脅迫状風のスコア。
- `c-specimen.html` — 博物学者の標本ノート。ピン留め標本とラテン語ラベル、季節ごとにおかしくなっていく手書きメモ。
- `d-retro.html` — ゲームボーイ風4色ドット絵。わかりやすいが「変」ではなく「懐かしい」。
- `index.html` — 4案をApp Storeのスクショ風に並べた比較ページ。

動物の絵は既存の絵にCSSフィルタ・ドット化・シール目玉を重ねただけ。採用する場合、A・C・D は12種＋空腹顔の描き直しが必要。B は既存の絵に目玉を足すだけで成立しやすい。
