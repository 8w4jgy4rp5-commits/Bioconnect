# ショップの入口（タイトル画面）の候補 — 2026-10-09

いまのタイトルは右上に「Crystals & No Ads」の大きな文字ボタン（Best の札の隣）。目立ちすぎるので、アイコンと置き場所を比べる。
アイコンはすべて宝石のひし形（復活ボタン・ショップ内と同じ緑）。新しい画像なし。

試作の作り: 各HTMLが本物の `index.html` を枠（iframe）で読み込み、`entry.js` が元の文字ボタンを隠して各案の入口を足す。本体のファイルは変更しない。
入口を押すと、ゲームの本物のショップが開く（元のボタンを押したのと同じ）。
ローカルで開く: リポジトリ直下で `python3 -m http.server 8790 --bind 127.0.0.1` → `http://127.0.0.1:8790/concepts/shop-entry-v1/1-icon-row.html` など。

## 候補
- **1 Icon in the button row**（`1-icon-row.html`）: 下の丸ボタン列（? ・台帳）の3つ目に宝石。無料3個が未受取のときだけ緑の点（台帳の赤い点と色で区別）。
- **2 Wallet chip**（`2-wallet-chip.html`）: 右上に「◆ 0 ＋」の所持数札。押すとショップ。ログイン前は0。
- **3 Crystal on the hill**（`3-crystal-in-scene.html`）: 丘のくぼみ（ライオンとキツネの間）に光る宝石と小さな "crystals"。ゆっくり上下（動きを減らす設定では止まる）。
