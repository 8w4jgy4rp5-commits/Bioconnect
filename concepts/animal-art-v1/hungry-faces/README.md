# 空腹の絵 — 残り4種の作り方

## 進捗

- **シマウマ 2026-09-30 完了。** `img/zebra-calm.png` / `img/zebra-hungry.png`。小物（スカーフ）で伝える型。
- **オオカミ 2026-09-30 完了。** `img/wolf-calm.png` / `img/wolf-hungry.png`。姿勢で伝える型。
- **トラ 2026-10-01 完了。** `img/tiger-calm.png` / `img/tiger-hungry.png`。体の外に出る形の型で、
  **画像生成AIを使わずに作れた唯一の1組**（`flare-tiger-aura.py`）。
- 残り: クマ・バッファロー・シカ・ライオン

**空腹の伝え方は今3つある。** 新しい動物はこのどれかに当てはめて考える:

| 型 | 例 | 44pxで読めるもの |
|---|---|---|
| 体の外に出る形 | ゾウの湯気 | 輪郭の外に新しい塊が出る。いちばん強い |
| 目立つ色が消える | シマウマのスカーフ | 彩度の高い一点が沈む。体に色の目印がある動物向け |
| 姿勢が変わる | オオカミ | 背が低くなる・輪郭が平らになる。灰色で目印のない動物向け |

トラは1つ目の型（体の外に出る形）だが、**その形が最初から絵の中にあった**という点だけが他と違う。

**道具**
- `check-pair.py <名前> <満腹> <空腹>` — シルエットの重ね図。**脚が灰色かどうかが唯一の本当の検査**
- `../make-face-pair.py` — 2枚を共通の枠で切る。足元のずれが判定、中心のずれは参考値
- `../measure-rig.py --sheet out.png --hungry wolf zebra` — 満腹と空腹をタイル上に並べて描く

2026-09-30の出発点では、ラダー10種のうち空腹で絵が変わるのは3種だけだった。ウサギ（パニック顔）、
キツネ（狩り顔）、ゾウ（湯気の怒り顔）。残り7種は `script.js` の `RIG` で
`head: { calm: 'X-whole', hungry: 'X-whole' }` ——満腹と空腹で同じファイルを指していて、
空腹は体が沈む（`sag`）だけで伝わっていなかった。**いま残っているのはクマ・バッファロー・シカ・ライオンの4種。**

## 先に分かっていること：44pxでは顔は3ピクセル

タイルは44px。そこに動物1頭が入るので、**表情を描き替えても誰にも見えない**。
既に成立している3種が何を変えているかを見ると答えが出る。

| 動物 | 空腹で変わるもの | 44pxで効いている理由 |
|---|---|---|
| ウサギ | 頭ごと差し替え＋耳 | 耳はシルエット。輪郭が変わる |
| キツネ | 頭ごと差し替え | 頭は体の1/3を占める |
| ゾウ | **湯気** | 体の外に出る新しい形。いちばん強い |

つまり守るべき規則はひとつ。

> **空腹版は、シルエットか、体の外に出る要素を変えること。目や口だけを描き替えない。**

## もうひとつの制約：体は1ミリも動かしてはいけない

ゲームは満腹の絵と空腹の絵を**その場で入れ替える**。2枚の体の位置がずれていると、
お腹が空いた瞬間に動物が横に跳ぶ。ゾウの2枚がうまくいったのは、同じ構図で描かれていて、
共通の枠で切り抜いたから。

だから理想は**既存の絵を読み込ませて、顔とその周りだけを描き替えさせる**こと（新規生成ではなく編集）。
新しく1枚描き直すと、まず構図がずれる。

切り出しは `make-face-pair.py` が2枚を**共通の枠**で切って、ずれを数値で報告する。
ずれが大きければ採用しない。

## 7種の方針

いずれも既存の採用版を元絵にする。元絵の一覧は `../../ASSETS.md`。

### オオカミ ✅ 完了（2026-09-30）
採用: **尻尾が垂れ、頭が肩より下がり、背中の毛が逆立ち、耳が後ろへ伏せる。口は閉じたまま。**
44pxで読むのは「長い灰色の獣が、低く平らになる」こと。指示書の当初案（低く構える＝クラウチング）は
**取り下げた**——体が動く変更はAIが失敗し、位置合わせも崩れる。代わりに輪郭の端4箇所だけを動かした。

ここで分かったこと:

**7. 牙を剥かせない。** 飢えと怒りは別物。「starving, exhausted and submission, never anger」と
明記したら一発で通った。トラでも同じ（凄みは静かな半眼から出る）。

**8. 「動かしてはいけないもの」を名指しする。** 「脚・足先・その間隔・胸・腹の線」と具体的に列挙したら、
足元が1画素も動かなかった（下端が両方とも1056）。「体を変えるな」では曖昧すぎる。

**9. `make-face-pair.py` の中心ずれ警告は姿勢変更では誤警報になる。** オオカミは尻尾が引っ込んだぶん
外接矩形が左から狭まり、中心が4.3%右へ動いたと報告された。体は1画素も動いていないのに。
**足元のずれが判定、中心のずれは参考値**に直した。本当の検査は重ね図。

**10. 古い切り抜きの動物はリグを測り直す。** オオカミの `oy` は 4.2 → 3.71。
ただし絵が同じなら、高さ・足元・上端・空腹時の4つの数値は**変更前と同じ値に戻せる**。
戻ったことが「枠を切り直しただけで、大きさは変えていない」証明になる。クマ・バッファローも同じ手順。

### クマ `img/bear-whole.png`（親子）— 指示文は `bear-prompt.txt`（2026-10-01、未送信）
**当初案「親が振り向いて牙を見せる」は取り下げた。** 牙を剥くと飢えではなく怒りになる
（オオカミで確定した原則7）。全身が黒く抜ける色も無いので、オオカミと同じ**姿勢型**にする。

採用する案: **親の頭が肩より下がり、代わりに肩のこぶが最高点になる。両方の耳が後ろへ伏せ、
子グマは頭と首だけを親の前脚へ向けて、クリーム色の鼻づらを隠す。**
44pxで読めるのはシルエットと、クリーム色の3つの点（親の鼻づら・親の胸の三日月・子の鼻づら）だけ。
頭を下げると、いちばん高い所と**いちばん明るい点が同時に下がる**ので二重に読める。
子グマの胴は動かさせない（体ごと動かす変更はAIが失敗する型）。

### バッファロー `img/buffalo-whole.png`
重い草食獣。空腹＝**頭を下げて角を前に構え、前足で地面を掻いて土煙を上げる**。
土煙はゾウの湯気と同じ役割で、体の外に出る形なので小さくても見える。

### シカ `img/deer-whole.png`
もともと「おびえた・痩せた」性格で、脚に震え線が描いてある。
空腹＝**あばらが浮くまで痩せ、首を落として地面を探す**。震え線を増やす。
盤面で唯一の縦長の絵なので、首を落とすと輪郭がはっきり変わる。

### シマウマ ✅ 完了（2026-09-30）
採用: 結び目がほどけ、2枚の端が膝まで垂れ、金がくすんだ黄土色になる。
44pxで player が実際に読むのは「**鮮やかな金が消える**」で、これがこの大きさで最も確実な合図だった。

## シマウマでやってみて分かったこと（残り4種に効く）

**1. 生成AIに「形」と「色」を同時に頼むと失敗する。**
1回目は「ほどく＋耳を伏せる＋色を変える」を一度に頼んで、AIが「体を固定したままではできない」と返した。
**形だけAIに頼み、色はこちらでPillowで計算する**と、両方とも簡単になった。
色はタイル上の44pxを見ながら強さを選び直せるので、再生成より速くて確実。
道具: `fade-zebra-scarf.py`（他の動物向けには色域を変えて流用する）。

**2. 元絵は「直前の出力」を使う。**
2回目はオリジナルではなく1回目の出力を添付して「スカーフを伸ばすだけ」と頼んだ。
変更が小さいほど体が動かない。1回目の出力が体を保てていたので、そこから積み上げるのが安全。

**3. 「保証できなくても出力して」と書く。**
AIは完璧な一致を保証できないと止まる。実際の出力は自己申告より良かった。
必須条件は「脚・ひづめ・尻尾・体の輪郭が動かないこと」だけだと明示する。

**4. 外接矩形のずれ検査は、絵が画布いっぱいのときは無意味。**
`make-face-pair.py` のずれ報告が 0.0px でも、それは「両方とも端まで絵がある」だけのことがある。
**2枚のシルエットを重ねた図**（赤＝満腹だけ／青＝空腹だけ／灰＝共通）で見るのが本当の検査。
これで「赤青が首まわりだけ、胴と脚は全部灰色」を確認した。

**5. シカとの取り違えは心配しなくてよかった。**
採用時の記録には「黄色いスカーフだけが見分けの決め手」とあったが、44pxで並べたらシカは
**オレンジで角つき**、シマウマは茶と生成りの縞で、色相からして別物だった。
だから色を落としても取り違えない。**採用時の懸念は、実際に並べて測り直す価値がある。**

**6. 枠が変わらないこともある。**
心配していたリグの測り直しは不要だった。2枚とも画布いっぱいなので共通枠＝元の切り抜きと同じで、
`zebra-calm.png` は旧 `zebra-whole.png` とバイト単位で一致。
ただしこれはシマウマの事情で、オオカミ・クマ・バッファローは古い緩い切り抜きなので同じにはならない。

### ライオン `img/lion-whole.png`
今は王冠をかぶって寝そべり、あくびをしている。空腹＝**起き上がる**。
あくびが本物の唸りになり、王冠が傾いてずれる。伏せ→半身を起こすのは輪郭が大きく変わる。

### トラ ✅ 完了（2026-10-01）
採用: **顔まわりの金のオーラが1.50倍まで伸びる。顔は1画素も触らない。**
咆哮させないのが前提だった（凄みは静かな半眼から出る。過去に8案やって全部やり直し）。
目を細くする案は見送り——44pxで目は1画素なので、やっても誰も見ない。

ここで分かったこと:

**11. 絵の中にもう在るものは、生成AIに頼まなくていい。** オーラは原画に焼き込まれていたので、
色相で抜いて外へ拡大するだけで済んだ。計算で作る＝体が動きようがない（体の下に敷くだけ）。
`flare-tiger-aura.py` は再実行すれば同じ絵が出る。**残り4種にこの型は使えない**（どれも形を変える案）。

**12. 輪郭線で描かれた形は、拡大する前に中身を塗りつぶす。** スパイクは「金の輪郭＋淡い芯」で
描かれているので、抜いた金をそのまま拡大すると中身の無いVが飛んでいく。外側から塗りつぶして
「塗りが届かなかった所＝内側」を拾う。毛に飛んだ金の点（150画素未満）は捨てる——拡大すると
体の外に砂粒として落ちる。

**13. 1枚だけ拡大しては駄目。0.06刻みで重ねる。** 1.4倍を超えると拡大版の内側の端が元の形の
外側の端を追い越し、オーラが「体から離れて浮いた輪」になる。間を埋めると1本の長い針になる。

**14. 伸ばしてよい方向は、タイルに空きがある方向だけ。** トラはタイル幅の134.2%で描かれていて
既に両端が切れている。横に伸ばすと共通枠が広がり、絵全体がタイルの中で縮む＝誰にも見えない
先端のために体の大きさを払う。上には12.7%空いていたので、伸びは上だけに許して横は切った。
枠は縦に131画素だけ伸び、`w` は触らず `oy` だけ測り直した（1.7 → -0.6）。

**15. 強さは本物の44pxで並べて選ぶ。** `tiger-spread-choice.png` に1.20/1.30/1.50/1.70を並べた。
1.20は「金が太る」だけで、オーラの**形**が変わるのは1.50から。1.70は楔のようになって
「動物自身の角」に見えだす。拡大図で選ぶと必ず弱すぎる方を選ぶ。

## 戻ってきたら

1. 透過が無い（JPEG・紙の上）なら先に `python cutout-bg.py <in>.jpg <out>.png`
2. `python make-face-pair.py <calm元> <hungry元> ../../img/<name>-calm.png ../../img/<name>-hungry.png`
   — 共通の枠で切り、ずれを報告する。警告が出たら採用しない
3. `script.js` の `SPRITE_FILES` に2つのキーを足し、`RIG` の `head` を
   `{ calm: '<name>Calm', hungry: '<name>Hungry' }` に変える
4. `python measure-rig.py` で大きさと接地線が動いていないことを確認
5. `node rules.test.js` と、実ブラウザで満腹・空腹の両方を44pxで見る

ファイル名は既存のゾウに合わせて `<animal>-calm.png` / `<animal>-hungry.png`。
今の1枚版 `<animal>-whole.png` は、差し替わるまで残す。

## 注意

- オオカミ・クマ・バッファローの現行3枚は、透明画素のバグがあった頃の**古い切り抜き**。
  リグの数値はその切り抜きに合わせてある。共通枠で切り直すと枠が変わるので、
  この3種は空腹版を入れる時にリグを測り直すことになる（`measure-rig.py` がその道具）。
- 頭だけを切り離す案（ウサギ・キツネ方式）は、**2枚そろってから**でないと意味がない。
  切り口に輪郭線が無い縁ができるだけで、何の得にもならない。
