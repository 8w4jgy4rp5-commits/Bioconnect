# あてっこ動画用の顔 — ChatGPTへの依頼文

TikTokのあてっこ動画（ライオン2匹 → トラ、最後はぞうの影絵）で使う、2つの顔。
焦り顔（`../panic-faces/`）と同じく、**絵を編集して顔だけ**変える。コードで目を描き足す方法は使わない。

## やり方（1枚ずつ）

1. ChatGPT で新しいチャットを開く。
2. このフォルダの `lion-source.png` を添付する。
3. 下の依頼文を1つ貼る。
4. 返ってきた画像を、このフォルダに表の名前で保存する。
5. Claude に「置いた」と伝える。大きさ・位置合わせは Claude がやる。

体や輪郭がずれて返ってきたら、もう一度生成し直してもらうのが早い。

| 顔 | 使う場面 | 保存する名前 |
|---|---|---|
| なんだ？顔 | ひとりのライオンが何かに気づき、首をかしげる | `lion-puzzled-src.png` |
| 見つめ顔 | もう1匹と目が合い、じっと見つめ合う | `lion-stare-src.png` |

## なんだ？顔

```
この画像を編集してください。変えるのは顔だけです。
それ以外はすべて、今の位置のまま変えないでください：
ポーズ、体、足、たてがみ、王冠、輪郭線、色、画像のサイズ、透明な背景。

新しい表情：「ん？今のなに？」という、ふしぎそうな顔。おもしろくてかわいい感じで。
- 大きくあくびしている口を閉じて、小さな口にする。少し片側に寄せて「むむっ」ととがらせる。歯は見せない。
- 目：両目を開ける。ふつうの大きさで、右の前方を見ている。
- まゆ：片方を高く上げ、もう片方は下げる（「はてな？」という顔）。
- 涙は消す。

絵のタッチはまったく同じにしてください：線の太さと線の色、ベタ塗りの色、やわらかい影。
はてなマーク、文字、背景、枠、影は入れないでください。
入力と同じサイズの、背景が透明なPNGで出力してください。
```
