# プレイ画面のデザイン3案（2026-10-03）

ユーザー指摘「詰め込みすぎ・UIが古臭い・人がやりたいと思えない」への候補。どれも未採用。
同じ試合途中の場面（夏・4,210点・空腹のオオカミ・手札は草→ウサギ→芽）を描いた静止モック。

- `a-clean.html` — 白基調・余白多め。スコア左上、目標1行＋12段の細い進捗バー、手札は「今置く1枚を大きく」。
- `b-pop.html` — 空と丘の背景、ぷっくり立体のマス、丸文字（Fredoka）。目標は吹き出し、手札はバスケット風。
- `c-dusk.html` — 夜の草原・ガラス風。12段をシルエットで並べ、到達済みだけ点灯。
- `index.html` — 3案をApp Storeのスクリーンショット風に横並びで比較するページ（スマホでは横スワイプ）。

共通の整理: 「How to play / Normal / New game」、12段の一覧、レベル表示、下のメモ欄はメニューへ移し、
盤面を主役にして iPhone Safari の表示領域（約390×700）でスクロールなしに収める。
`art/` のウサギ・キツネ・芽・草は、実際のゲームが描いた絵を透過で切り出したもの（ウサギ・キツネは部品リグのため1枚絵が無い）。
