# タイトルの動物の見せ方の候補 — 2026-10-09

ユーザーの指摘: 「ゲームに出てくる動物がそのまま出る感じがチープ」「切り取られてそのまま置いてるみたい」。
原因の見立て: 盤面用の絵を丘に貼っているだけで、足元の影・草への埋まりがなく、昼の色のまま夜の背景に乗っている。

試作の作り: 各HTMLが本物の `index.html` を枠（iframe）で読み込み、`art.js` が丘の上の見せ方だけ変える。新しい画像なし、本体のファイルは変更しない。
ローカルで開く: リポジトリ直下で `python3 -m http.server 8790 --bind 127.0.0.1` → `http://127.0.0.1:8790/concepts/title-art-v1/1-blend.html` など。

## 候補
- **1 Blend into the night**（`1-blend.html`）: 色は残し、月明かりの色に落とす（彩度・明るさを下げ、月側の縁を明るく）。足元に影、手前に丘と同じ色の草、薄い霧。奥（山の上）のシマウマ・ゾウはさらに暗く、わずかにぼかす。
- **2 Silhouettes**（`2-silhouette.html`）: 動物を黒い影にして、山の後ろに大きな満月。上の小さな月は消す。輪郭だけ月の光で縁取る。丘も暗くする。
- **3 Eyes in the dark**（`3-eyes-in-dark.html`）: 動物はゾウ以外隠し、草むらに光る目（ライオン金・キツネ橙のつり目・ウサギ小さい白・遠くの緑・紫の何か）がまばたき。ゾウだけ闇の中にうっすら。動きを減らす設定ではまばたきしない。
