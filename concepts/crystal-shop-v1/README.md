# クリスタルショップの画面候補 — 2026-10-09

ユーザー決定: 入手・交換・入口は DEVELOPMENT.md の記録どおり（購入4種＋初回無料3個／復活とNo Ads／タイトル・メニュー・ゲームオーバー）。
雰囲気はE案（Cozy Eldritch）、形は A「カード型」。その中で3つの並べ方を比べる。

ローカルで開く: リポジトリの直下で `python3 -m http.server 8790 --bind 127.0.0.1` → `http://127.0.0.1:8790/concepts/crystal-shop-v1/a1-tarot-grid.html` など。
色・フォントは eldritch.css / revive-ui-v1 と同じ値（`shop.css`）。宝石は復活ボタンのひし形、太陽は Wait for Dawn と同じ形。新しい画像は使っていない。価格・購入はダミー。

## 候補
- **A1 Tarot Grid**（`a1-tarot-grid.html`）: クリスタルが主役。縦長カード2×2、量が増えるほど宝石の山が大きい。65個に「MOST GLOW」。No Ads は下の横長カード。390×844 では少しスクロールが必要（全体952px）。
- **A2 Ledger List**（`a2-ledger-list.html`）: No Ads を上の大きいカード（"Hush the Meadow"）、クリスタルは古い本のページに1行ずつ。390×844 に収まる。
- **A3 One Card Picker**（`a3-one-card-picker.html`）: 大きいカード1枚＋下の4つのチップで量を選ぶ。購入ボタンは1つだけ（復活画面の「押せるのは1つ」と同じ考え）。`?pack=0〜3` で最初の選択を変えられる。

## 全案共通
- 一番上のログイン欄をやめ、「買う／無料を受け取る」を押したときだけログインを出す想定（下の注意書きに一行）。
- 所持数（You hold N Crystals）を見出しの下に常に出す。
- ボーナス表記（+1 / +5 / +15）は 5個=$1 を基準にした差。

## 決定・却下
- **採用: A1 Tarot Grid**（2026-10-09、ユーザー「一番左の案がいい」）。本体の #shopModal に反映済み。本体ではサインイン欄を一番下に残した（テストと既存の流れを保つため、折りたたみはしていない）。
- 保留: A2（No Ads を先に見せたい場合の控え）、A3（購入ボタンを1つにしたい場合の控え）。却下理由は「ユーザーがA1を選んだため」で、案そのものの欠点の指摘はなし。
