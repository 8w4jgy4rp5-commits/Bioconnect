# 動物の呼吸と個性モーション（2026-10-03）

盤面の10種類の動物に、静かな呼吸と、ときどき出る個別のしぐさを組み合わせた。
ウサギは耳と尻尾、キツネは尻尾と鼻先、シカは物音を聞く姿勢、シマウマは重心移動、
バッファローは頭を下げる、オオカミは遠吠え、クマ親子は寄り添う揺れ、
ライオンはあくびの姿勢を伸ばす、トラは伸び、ゾウはゆったり重心を移す。
ウサギ/キツネは既存の部品を動かし、他の一枚絵は足元を軸に姿勢を動かす。
オオカミだけは口を開けて上を向く専用の一枚絵を追加した。鳴き声の音は追加していない。

## 遠吠え素材

- ゲーム用: ../../img/wolf-howl.png（透過PNG、220×173）

- 生成結果の下半身は完全な画素一致ではない。短い補間で切り替え、足元の高さを揃えた。
- 遠吠え素材の読み込みが失敗しても通常のオオカミは表示できる。

## 時間と停止

script.js の ANIMAL_GESTURES がしぐさの間隔と長さ。個体ごとに間隔を±15%、
初回の待ち時間を3〜10秒にずらす。オオカミは約15〜21秒おき、1回2.8秒。
CSSの呼吸は個体ごとに位相をずらし、セルを描き直しても続きから動く。
WeakMapでセルの物体とモーションの状態を紐付ける。配置・合体の乱数は使わない。
追加の姿勢を描き直すのは動いている個体のみ、最大24fps。息はCSSが担当。
空腹ではしぐさを小さくし、空腹のオオカミは遠吠え用の絵を使わない。
メニュー/ガイド/タイトル/タブ非表示/終了/ゾウのお祝いでは時計と呼吸を止める。
prefers-reduced-motionではしぐさと呼吸を止め、再描画でも静止を維持する。
