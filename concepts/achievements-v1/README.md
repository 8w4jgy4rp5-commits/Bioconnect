## 決まった実績の中身
- 第1弾はコレクター系と図鑑（Field Guide）のみ。広告復活したプレイも数える。
- ゾウだけ特別：1 / 5 / 10 に加えて、ゾウにしかないダイヤモンド（50）。ゾウは過去分も `lifetimeElephants` からさかのぼれる。
- トラ 1/5/25、ライオン 1/25/100、オオカミ＋クマ 25/250/1,000、Ecosystem（合体で育てた動物の合計）1,000/10,000/100,000。
  ライオン以外の数字はシミュレーションからの仮決め（casual bot 60回で1回あたり：ライオン1.6、トラ0.2、オオカミ＋クマ約18、合体で育った動物約250）。人の操作は bot より遅いので、実際はもっと少ない可能性がある。
- ウサギ〜バッファローは図鑑（全10種に出会う）でだけ使う。

## 3案
- `a-shrine.html` — 祭壇。ゾウはろうそく付きのアーチ型の祭壇に飾り、ほかの動物は下の棚に並べる。いちばん分かりやすい。
- `b-ledger.html` — 博物学者の台帳。メダルは封ろう。ゾウだけ金縁の図版が貼り付けてあり、ほかは手書きの行。図鑑はピン留め標本。
- `c-eyes.html` — 見守る夜空。メダルは目で、段階ごとに開く。ゾウは空の巨大な目を4つの輪が囲み、いちばん外側（ダイヤ）は点線のまま。今の Cozy Eldritch に最も寄せた案。

## 決定（2026-10-05）と置き場所のモック
- デザインは **B 台帳** に決定。
- 入口は **タイトル画面の「?」の横に台帳ボタン**（案1）。新しいメダルがあるときは赤い点。

- お知らせの見た目は **2 台帳の紙切れ** に決定。
