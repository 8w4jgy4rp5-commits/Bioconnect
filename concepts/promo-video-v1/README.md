# X用プロモ動画 v1（試作）

2026-10-10 開始。X に投稿する縦長（1080×1920・30fps）の紹介動画。公開・投稿は未実施（別途確認）。

## 決まっている構成（約30秒）
1. 0〜6.5秒: 同じ動物2匹が合体して次の動物へ（芽→…→トラ）。だんだん速くなる。合体ごとに「ぽん」、音程が上がる。
2. 6.5秒: トラ2匹が離れたまま止まり、BGMが止まる。鼓動2回。「Next is…?」とゾウのシルエット。
3. 8秒: 白くなる（「シャーン」）→ プレイ映像へ（未制作）。
4. プレイ映像: 指マーク（B）、隅にシルエットを残す（A）、捕食1〜2回をスロー＋「EAT!」（D、キツネ→ウサギ想定）。
5. 最後: ゾウ誕生でシルエットが答え合わせ → ロゴと URL、鐘の音。

## 音
- BGM「Tiptoe Hollow」: このために書いたオリジナル曲（Dマイナー、120BPM、8小節ループ）。ルイージマンションのような「怖いけどコミカル」な雰囲気を目指したが、他作品のメロディ・録音は使っていない（著作権のため）。
  楽器はすべて合成: チューバ風ベース（ズン）、チェンバロ（チャッ）、口笛メロディ、テルミンのひゅ〜ん、後半はピチカート。
- 効果音: ぽん（合体）、ドクン（鼓動）、シャーン（白くなる瞬間）。

## ファイル
- `index.html`: 試聴・プレビュー。「Intro」で映像＋音、「BGM only」で曲だけ（ループ2回）。
- `promo-audio.js`: 曲と効果音。リアルタイム再生とオフライン書き出しで同じものを使う。
- `promo-intro.js`: 冒頭の映像。`render(t)` が時刻 t の1コマを描く（状態を持たない）。
- `sprites/`: ゲーム本体の描画（標準スキン）から書き出した各動物のタイル画像。`export-sprites.cjs` で再生成。
- `render.cjs`: 1コマずつ撮影して `out/promo-intro.mp4` と `out/bgm-preview.mp4` を作る（ffmpeg 必要）。

## 作り直し方
```
python -m http.server 8770 --bind 127.0.0.1      # リポジトリ直下で
node concepts/promo-video-v1/export-sprites.cjs   # 動物の絵が変わったとき
node concepts/promo-video-v1/render.cjs
```
