# 復活画面（ゲームオーバー時）のUI候補 — 2026-10-09

`candle-candidates.html` をブラウザで開くと3候補を見比べられる。上の切り替えで3つの場合を表示する。
（No Ads あり・無料あり／No Ads あり・使用済み／No Ads なし）

## 採用: CANDLE 3「燭台と古い本」
- 上に3本立ての燭台、画面全体を古い本のページの額縁（二重線・ひし形の区切り）にする。
- 押せる大きいボタンは1つ。今日の無料が残っていれば「Wait for Dawn」（金色に光る）、なければ同じ場所が「Offer 1 Crystal」（緑色に光る）に変わる。
- No Ads を持っていない人には、夜明けのボタンを灰色にして鉄の鎖2本（X字）と南京錠をかけ、その下にクリスタルのボタンを置く。鎖のボタンを押すとショップの No Ads を開く。下に「hush the meadow to free the dawn」。
- 最後に「Let it rest · end the game」。
- 見出しは仮: "The Meadow Falls Still / But it is only pretending. (probably.)"

## 保留（変更時の控え）
- CANDLE 1「両脇にろうそく」: ボタンの左右に1本ずつ。いちばんシンプル。
- CANDLE 2「ボタンの上にろうそく」: ボタンを祭壇の台にして、上にろうそくとろうの垂れ。
- その前段階（同じアーティファクトの過去版）: 丸いメダル型の祭壇、古い本、盤面のマス、すっきりタイプライターの4スタイル。ユーザーの判断で「丸より横長」になった。
  過去版は https://claude.ai/artifact/BN6qFkibdrEKoY8dM8ycTQ の版履歴に残っている。

## 却下・保留の理由
- 明るいパステル調の案（初版）: 元のハロウィン風の雰囲気から離れすぎる。
- `bear-calm.png` をCSSでさかさまにしただけの「死んだふり」: 子グマまで反転し絵として成立しない。動物は後回し。
  入れるなら bear-calm.png を元に生成AIで仰向けの絵を作る。
- ボタン3つ並び・小さい鎖アイコン: 構成を「大きいボタン1つ＋鎖」に整理したため置き換え。

ゲームに反映済み。クリスタル0個の扱いは、No Adsなし→広告、No Adsあり→Find Crystals で決定。
