# アイコン候補 v1（2026-10-17）

依頼: ウサギを大きく、背景は「草」と「ハロウィン」が混ざった雰囲気。3案。
ウサギはゲームの絵をそのまま使う（ユーザー指定）。すべて候補で、採用はまだ決まっていない。

- ウサギ: `img/ref/rabbit-reference.jpg`（1024px、ゲームのウサギの元絵）のピンク背景を `key.py` で抜いた `rabbit-cutout.png`。絵そのものは描き変えていない。
  ゲームの `img/rabbit-pose.png` は155pxでアイコンに拡大するとぼやけるため、同じ絵の高解像度版を使った。
- A `A-moonlit-meadow`: 夜の草原。満月を背にしたウサギ、コウモリ、草むらにジャック・オ・ランタン2つ。
- B `B-pumpkin-dusk`: 夕暮れのかぼちゃ畑。紫〜オレンジの空、鼻先に大きなジャック・オ・ランタン。
- C `C-cozy-eldritch`: 今の標準スキン（Cozy Eldritch）の色。暗い苔色、三日月、紫の触手、草むらからのぞく目、緑に光るかぼちゃ。

`gen.py` が背景を作図してSVGを書き出す（SVGは同じフォルダの rabbit-cutout.png を参照）。PNGはChromiumで512pxに書き出したもの。
`compare-48px-x4.png` は48pxに縮小して4倍に拡大した見え方の確認用。

初版（記録）: 最初はウサギを正面顔で描き起こしたが、「いまあるウサギをそのまま使う」指示で差し替え。
