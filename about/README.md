# Bioconnect LP — 公開先 https://bioconnectpazzle.com/about/（2026-10-20に landing/ から移設）

日英切り替え、2匹のウサギ→キツネの8秒ループ紹介アニメ、実プレイスクショ3枚の拡大、音声つき実プレイ録画、SNS案内を備えた独立LPです。配色は深緑・クリーム色・黄緑。ゲーム本体のコードやルールは変更していません。

## 開く

正本では `node about/server.cjs` を実行し、`http://127.0.0.1:8789/` を開く。既に同じポートで起動中ならそのURLを利用する。HTMLは直接開くことも可能。

作業プレビュー側では `node server.cjs` で dist/ を配信します。外部への公開・コミット・pushは行っていません。

## 編集

- `index.html`: 構成。作業プレビュー側は dist/index.html。
- `style.css`: 配色・レイアウト・CSS紹介アニメ。レスポンシブ、動き軽減設定に対応。
- `app.js`: 日本語/英語の全コピー、言語設定の保存、画像/動画ダイアログ。
- `config.js`: ゲームのURLとTikTok / YouTube Shorts / Reddit / X（Instagramは2026-10-19に保留）の個別URL。
- URLが空の媒体は「準備中 / Coming soon」の非リンク。実アカウントURLを入れるとリンクに変わる。http/httpsのみ利用。

紹介アニメは既存の2D素材をCSSで動かしたコンセプト試作です。表情の新規描画やMP4書き出しは含みません。「…?」の吹き出しと首をかしげる動きで驚きを表現。録画のMP4は別途実プレイ映像です。BGMは再生ボタンを押したときのみ再生します。

## 素材

動物は正本 img/ の既存素材。実プレイ画面/録画は旧作業フォルダ output/playwright/gameplay-capture/recorded-applause/ からコピーした2026-10-16頃の撮影素材です。現在とUIが異なりうることをページ内にも記載しています。

Google Fontsを読み込みます。接続できない場合はOSの日本語フォントとserif/sans-serifへ切り替わります。
